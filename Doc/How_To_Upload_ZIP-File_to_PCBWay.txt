How to Upload the ZIP-file for the PCB to PCBWay
-------------------------------------------------------------------
Download the PCB Zip file from WICS GitHub
-------------------------------------------------------------------
1. Open your Browser an go to: https://www.pcbway.com/
2. Logon on or Create a Account with all your shipping information.
3. From the Top Menu click "PCB Instant Quote"
4. Click on the Orange "Upload files and checkout" button
5. Click on the Grey Button "Add Gerber File"
6. Select the ZIP file you downloaded from WICS GitHub.
7. Select Quantity (5-10 is normally the same price).
8. Select the Color yo want.
9. Click "Save to Cart"
-------------------------------------------------------------------
The Shipping and Taxes is added to the PCB. 
Make sure that you order all PCB wanted at the same time (saving money)
