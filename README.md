# WICS-Hardware
Here you can download the files for WICS Board: Schematic and PCB files (KiCad 9,10) and zip-file to upload to your PCB manufacture.
Each Board (PCB) has its own folder.
All the files are free to download and use. I've done my best to secure quality and function and did a lot of testing. But I can't provide any warranties, support or assistance.  If you find any malfunction I would appreciate it if you let me know, 
Using the WICS PCB:s will be your responsibility.
